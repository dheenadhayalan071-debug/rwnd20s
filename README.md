# rwnd20s. — Shopify Online Store 2.0 Liquid Theme

Upload-ready **Shopify Online Store 2.0** Liquid theme (`rwnd20s. Metallic Chrome OS 2.0`).

## Theme Directory Structure

```text
├── layout/
│   └── theme.liquid
├── config/
│   └── settings_schema.json
├── locales/
│   └── en.default.json
├── assets/
│   ├── theme.css
│   └── theme.js
├── snippets/
│   └── cart-drawer.liquid
├── sections/
│   ├── header.liquid
│   ├── main-storefront.liquid
│   ├── main-product.liquid
│   ├── main-collection.liquid
│   └── footer.liquid
└── templates/
    ├── index.json
    ├── product.json
    └── collection.json
```

## How to Upload to Shopify Admin

1. Connect this GitHub repository directly in **Shopify Admin → Online Store → Themes → Add theme → Connect from GitHub**, **or**
2. Zip the folders (`layout`, `config`, `locales`, `assets`, `snippets`, `sections`, `templates`) and upload via **Shopify Admin → Online Store → Themes → Add theme → Upload zip file**.
